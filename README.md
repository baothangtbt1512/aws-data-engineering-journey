1. **Thi đỗ chứng chỉ AWS Certified Data Engineer - Associate (DEA-C01)**.
2. **Xây dựng Portfolio thực chiến để ứng tuyển vị trí Thực tập sinh Data Engineer (Data Engineer Intern / Fresher)**.
3. Giáo trình dựa trên nền tảng **DataTalksClub Data Engineering Zoomcamp** kết hợp hệ sinh thái **Amazon Web Services (AWS)**.

## 🛠️ Công nghệ sử dụng (Tech Stack)

* **Lập trình:** Python 3.11, SQL (PostgreSQL, Trino/Athena dialect)
* **Containerization & IaC:** Docker, Docker Compose, Terraform
* **Kho lưu trữ & Xử lý:** Amazon S3, Amazon Athena, Amazon Redshift, PostgreSQL
* **Big Data & Streaming:** Apache Spark (PySpark), Apache Kafka, Amazon Kinesis, AWS Glue
* **Data Transformation & Orchestration:** dbt-core, Apache Airflow / Mage AI, GitHub Actions
* **Table Formats:** Apache Iceberg, Parquet
