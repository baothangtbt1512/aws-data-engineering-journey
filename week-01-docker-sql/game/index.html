           BÍ KÍP 30 KHÁI NIỆM DATA ENGINEER CỐT LÕI
        

        
      

      

        

          
1. Docker Network & Volumes

          
Trong cùng network, dùng tên service (ví dụ postgres) thay vì localhost. Dùng Volume để dữ liệu không bị mất khi docker compose down.

        

        

          
2. Chống lỗi chia cho 0 & Xử lý NULL

          
NULLIF(val, 0): biến 0 thành NULL để phép chia an toàn. COALESCE(col, default): gán giá trị mặc định khi gặp NULL.

        

        

          
3. Xử lý thời gian Data Warehouse

          
DATE_TRUNC('day', dt): đưa về đầu ngày (00:00:00). EXTRACT(HOUR FROM dt): trích xuất số giờ từ 0-23.

        

        

          
4. Window Functions cốt lõi

          
ROW_NUMBER(): Khử trùng lặp (rn = 1). DENSE_RANK(): Xếp Top N không nhảy cóc số. LAG() / LEAD(): Lấy dòng trước / sau. SUM() OVER (ORDER BY dt): Tính tổng dồn lũy kế.

        

        

          
5. Tối ưu hóa Database (Indexing)

          
EXPLAIN ANALYZE để xem Query Plan. B-Tree Index chuyển từ Seq Scan (chậm) sang Index Scan (nhanh).

        

        

          
6. AWS DEA-C01 Storage & Compute

          
OLTP (Aurora/RDS) tra cứu theo hàng <10ms. OLAP (Redshift/Athena) quét hàng triệu dòng. S3 Lifecycle chuyển dữ liệu cũ sang Glacier tiết kiệm chi phí.
