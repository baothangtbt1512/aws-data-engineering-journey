           BÍ KÍP NHỚ NHANH (SQL & DOCKER CHEAT SHEET)
        

        
      

      

        

          
1. Docker pgAdmin kết nối Postgres

          
Host name: postgres (tên container trong docker-compose, KHÔNG ĐƯỢC dùng localhost).

        

        

          
2. Chống lỗi chia cho 0 (Division by Zero)

          
Dùng: NULLIF(fare_amount, 0). Nếu mẫu bằng 0 biến thành NULL, phép chia ra NULL chứ không crash.

        

        

          
3. Khử trùng lặp dữ liệu (Deduplication)

          
Dùng: ROW_NUMBER() OVER (PARTITION BY id ORDER BY updated_at DESC) AS rn rồi lọc WHERE rn = 1.

        

        

          
4. So sánh với chuyến trước / sau

          
LAG(col): Lấy dòng trước. LEAD(col): Lấy dòng sau.

        

        

          
5. Xếp hạng Top N không bị nhảy số

          
DENSE_RANK(): Đồng hạng 1, tiếp theo vẫn là hạng 2 (khác với RANK() sẽ nhảy lên hạng 3).
